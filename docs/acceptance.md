# 요구사항별 인수 기준

현재 모든 제품 기능은 미구현·미검증이다. 장비 인식 결과만 hardware.md에 별도로 기록했다.

| ID | 기능 | 통과 기준 |
|---|---|---|
| AUTH-01 | ID/PW | 실제 .env로 로그인 성공, 오답 거부, 로그아웃 후 세션 거부 |
| AUTH-02 | 보호 경계 | 미인증 API/썸네일/다운로드/스트림/WebSocket 차단, CSRF 요청 거부 |
| DISK-01 | 드라이브 | 실제 USB 용량/상태 표시, 분리·재연결 복구, 기존 파일 보존 |
| DISK-02 | 루트 제한 | `..`, symlink, 다른 드라이브/시스템 경로 접근 거부 |
| SMB-01 | 공유 | 선택 폴더만 Windows SMB 접근, 읽기 전용/쓰기 권한 확인 |
| IDX-01 | 내용/메타데이터 | txt/docx/hwpx/pdf 표본과 이름/타입/날짜 필터 검색 |
| IDX-02 | 변경 추적 | 생성/수정/이동/삭제 반영; 이벤트 누락 후 대조로 복구 |
| IDX-03 | 72시간 교체 | 시간 주입 테스트 및 실제 스케줄 확인; 새 세대 실패 시 기존 보존 |
| IDX-04 | HWP | 구형 HWP 실파일 검증 또는 미지원 표시, HWPX와 구분 |
| PRE-01 | 이미지 | JPEG/PNG/HEIC/HEIF 회전·색상·썸네일, 원본 무변경 |
| PRE-02 | 영상 | Apple MOV H.264/HEVC 표본 Chrome 재생·탐색, 변환 취소와 캐시 제한 |
| CHAT-01 | 기록 | 재시작 후 세션 복원, 세션 간 문맥 분리, 삭제·내보내기 |
| CHAT-02 | 검색 도구 | 한국어 쿼리의 폴더/유형/날짜 조건과 실제 파일 카드 일치 |
| LLM-01 | 자원/품질 | 모델별 한국어 도구 정확도와 동시부하 RSS/속도 기록, OOM 없이 반복 통과 |
| ST-01 | 기기 | 실제 계정 목록/상태 조회와 지정 시험 기기 제어 |
| ST-02 | 인증 | 만료·갱신·401·429 처리, 로그 토큰 미노출 |
| FLOW-01 | 프리셋 | 저장·재실행·실패 단계 기록, 중복 입력 방지, 재시작 후 보존 |
| PANEL-01 | 터치 | 실제 DSI 화면에서 로그인·기기·Flow 조작 및 회전/터치 좌표 확인 |
| VOICE-01 | 호출 | 마이크 연결 후 “얼터” 한국어 명령 표본과 오탐/지연 측정 |
| CAM-01 | 모니터링 | 인증된 Chrome 스트림, 동시 미리보기·녹화 시작/중지 |
| CAM-02 | 저장 | 지정 폴더, FAT32 분할, 공간 부족·분리 시 오류와 재생 가능한 결과 |
| GST-01 | 제스처 | 다섯 동작 실제 카메라 표본, 유지/해제/쿨다운, 다른 손동작 오탐 기록 |
| GST-02 | 연동 | 명시적 켜기와 매핑, 끈 상태에서 실행 0회, Flow/챗봇 연결 |
| OPS-01 | 재현 | 새 환경 의존성 설치, systemd 재부팅 복구, DB 백업/복원 |
| PUB-01 | 게시 | GPL 전문, 비밀정보 제외, 원격 commit과 로컬 일치 |

실측 성능 합격 수치는 표본 측정 후 정한다. “실시간” 또는 “OOM 없음”을 단 한 번의 실행으로 보장하지 않는다.
