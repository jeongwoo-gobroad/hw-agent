얼굴과 손동작으로 Flow 실행

얼굴의 존재와 다섯 손동작을 Pi에서 감지합니다. 특정인의 신원은 구별하지 않습니다. 브라우저를 닫아도 계속 실행되며, 켜 둔 설정은 서버 재시작 후 복원됩니다.

상태 확인 중

기본값은 충분히 유지했을 때 한 번 실행입니다. 반복을 켜면 보이는 동안 Flow 완료 후 지정 시간만큼 기다렸다가 다시 실행합니다. 동시에 실행 중인 감지 Flow가 있으면 추가 실행은 건너뜁니다.

재감지 대기: 감지 대상이 사라진 뒤 이 시간 이상 지나면 다시 한 번 실행할 수 있습니다. 실행 후 대기는 재감지에도 적용됩니다. 얼굴은 화면 전체의 존재 기준이며 사람별 추적은 하지 않습니다. 감지는 녹화를 자동 시작하지 않습니다. 카메라 끄기를 누르면 상시 감지도 중지됩니다.

접속 보호 안내

내부망과 외부 접속은 각각 로그인합니다. 외부 접속에는 매번 일회용 보안 문자가 필요하며, 잘못된 보안 문자도 로그인 실패로 집계합니다. 이미 진행 중인 차단은 기존 종료 시간까지 유지됩니다.

같은 공유기를 쓰는 사용자는 외부 접속 주소를 공유할 수 있습니다. 11977 포트는 내부망 전용으로 유지하고, 공유기에는 8080 포트만 연결하세요.

동작 인식 카메라 방향

회전 후 화면 기준으로 반전합니다. 저장한 방향을 카메라 미리보기·얼굴/손동작 인식·녹화에 함께 적용하며 재시작 후에도 유지합니다. 녹화 중에는 변경할 수 없습니다.

로그인 계정과 음성 입력

아이디와 비밀번호는 프로젝트 루트의 .env에서 관리합니다. 변경 후 서비스를 재시작하면 기존 세션이 종료됩니다.

마이크를 연결하면 터치 패널에서 한국어 음성 입력과 ‘얼터’ 호출 대기를 사용할 수 있습니다. 음성은 Pi에서 처리합니다.
