내부망 SMB 공유

색인과 독립적으로 설정합니다. 드라이브의 ‘SMB 폴더 선택’에서 공유할 폴더를 고르세요.

아직 공유 폴더를 선택하지 않았습니다.

Windows 파일 탐색기에서 \\192.168.0.44\Alter-공유이름으로 접속합니다. SMB는 내부망에서만 사용할 수 있습니다.

SMB 사용자는 jeongwoo입니다. 공유 비밀번호는 장치 설치 시 설정합니다. Windows 자격 증명 창에서 jeongwoo 계정을 사용하세요. 네트워크 목록에 없어도 위 주소로 직접 접속할 수 있습니다.

얼굴과 손동작으로 Flow 실행

얼굴의 존재와 다섯 손동작을 Pi에서 감지합니다. 특정인의 신원은 구별하지 않습니다. 브라우저를 닫아도 계속 실행되며, 켜 둔 설정은 서버 재시작 후 복원됩니다.

상태 확인 중

기본값은 충분히 유지했을 때 한 번 실행입니다. 반복을 켜면 보이는 동안 Flow 완료 후 지정 시간만큼 기다렸다가 다시 실행합니다. 동시에 실행 중인 감지 Flow가 있으면 추가 실행은 건너뜁니다.

재감지 대기: 감지 대상이 사라진 뒤 이 시간 이상 지나면 다시 한 번 실행할 수 있습니다. 실행 후 대기는 재감지에도 적용됩니다. 얼굴은 화면 전체의 존재 기준이며 사람별 추적은 하지 않습니다. 감지는 녹화를 자동 시작하지 않습니다. 카메라 끄기를 누르면 상시 감지도 중지됩니다.

나의 보관함

사진, 동영상, Live Photo를 함께. 원본은 그대로 보관합니다.

브라우저 현지 시간 기준입니다. 촬영 정보가 없으면 수정일을 사용하며 상세 화면에서 구분합니다.

사진 대상 폴더

사진 관리에 사용할 폴더를 별도로 등록합니다. 등록하면 사진·동영상만 자동 처리하며, 파일 색인이나 SMB 공유 설정은 바뀌지 않습니다.

10분마다 변경을 확인합니다. 등록 해제는 사진 색인과 얼굴 묶음만 정리하며 원본을 삭제하지 않습니다. 연결이 끊어진 드라이브도 해제할 수 있습니다.

동작 인식 카메라 방향

회전 후 화면 기준으로 반전합니다. 저장한 방향을 카메라 미리보기·얼굴/손동작 인식·녹화에 함께 적용하며 재시작 후에도 유지합니다. 녹화 중에는 변경할 수 없습니다.

접속과 계정

인증정보는 장치의 프로젝트 루트 .env에서 관리합니다. 변경 후 서비스를 재시작하면 이전 로그인 세션이 무효화됩니다.

SmartThings는 ‘스마트홈 · Flow’에서 삼성 계정으로 연결합니다. 연결된 계정의 인증은 자동으로 갱신됩니다.

대화와 색인은 이 Raspberry Pi에 저장됩니다. 터치 패널에서 마이크를 연결하면 한국어 음성 입력과 ‘얼터’ 호출 대기를 사용할 수 있습니다. 음성은 Pi에서 처리합니다.

모델과 운영 범위

언어 모델: Qwen3.5-4B · Q4_K_M 양자화 · llama.cpp · 문맥 4,096토큰. 대화 기록은 저장되지만 답변에는 최근 일부 대화만 사용합니다.

내부망과 ngrok HTTPS 주소에서 같은 ID/PW로 로그인할 수 있습니다. 무료 ngrok의 월 1GB 전송 한도는 카메라 스트리밍으로 빠르게 소진될 수 있습니다. 영상 미리보기는 최대 10분 프록시이며 원본 전체는 다운로드로 받을 수 있습니다. 생성일을 제공하지 않는 파일시스템은 생성일 검색에서 제외됩니다.
